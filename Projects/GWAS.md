# Genome‑Wide Association Study (In Progress)

This project is an ongoing Genome‑Wide Association Study exploring genetic factors associated with an infectious disease outcome. The work is being carried out as part of a research project supervised by an MRC‑IEU investigator, using standard GWAS pipelines and high‑performance computing.

Because the analysis is still in progress, only a brief outline is provided here.

---

## Current Focus

- Setting up phenotype definitions and covariates  
- Running sample and variant quality control  
- Preparing population structure correction (PCA / mixed models)  
- Building the association pipeline on HPC  
- Early visualisation (Manhattan & QQ plots)  

---

## What This Project Will Eventually Include

- Full QC workflow  
- Association modelling  
- Post‑GWAS annotation  
- Biological interpretation of top loci  
- Integration with infection biology and host‑response pathways
